# 数据与权限说明

扩展用途是把用户选择的网站播放信息交给本机 TaskbarLyrics，显示歌词并控制对应媒体。

扩展只在用户授权且桌面网站列表中启用的地址采集。处理字段为网站 origin（协议、域名、端口）、歌名、歌手、专辑、封面候选地址及尺寸/类型、播放状态、播放位置、时长、速率、可跳转区间、逐项控制能力、数据来源与年龄、曲目版本、控制执行结果，以及用于路由的标签页/文档/媒体标识。普通媒体信息不足时会读取页面标题并标记备用来源。不发送网页地址的完整路径和查询参数、网页正文、Cookie、账号密码或完整浏览历史。

封面资源地址是地址限制的例外：会传递图片完整路径及必要参数到本机桌面端，用于异步加载。桌面按候选地址向图片服务器请求封面，不转发浏览器登录信息；公开图片 CDN 可访问，私有网络只允许用户获准网站的同源图片。图片地址不成为网站匹配规则，不原样写入普通诊断日志；图片在内存中按当前会话与曲目代次缓存，不新增封面历史库。

上述播放信息通过 Native Messaging 和当前 Windows 用户可访问的命名管道发送到本机桌面程序。扩展没有远程服务器、遥测或分析 SDK，不自行向网络发送播放数据。桌面程序按其现有设置向歌词服务查询歌名、歌手等信息，并加载封面，也可能按现有规则缓存歌曲与歌词；不能将扩展的本地通信表述为整个歌词功能完全离线。

本地扩展存储保留随机配置文件标识、网站配置、授权状态和连接状态，不保存播放历史。浏览器网站权限由浏览器管理，支持随时撤销；撤销后该网站不再作为扩展候选。桌面网站列表保存在现有 settings.json 中，删除网站不自动删除浏览器已授予的权限，可在扩展管理页撤销。

权限用途：`nativeMessaging` 连接桌面程序；`storage` 保存本机状态；`scripting` 在已授权网站运行随扩展打包的媒体脚本；`activeTab` 在用户主动打开弹窗后获取当前地址；`alarms` 在桌面程序重新启动后重试连接。HTTP/HTTPS 可选网站权限按用户逐站授权申请，不在安装时请求全站读取权限。

网页主执行环境负责读取标准媒体对象；页面可修改自身元数据，因此这些字段属于不可信输入。扩展和桌面端限制消息长度、字段和协议版本，并由浏览器提供真实的发送文档身份。扩展卸载后本地扩展存储被浏览器移除；桌面程序的设置与歌词缓存仍遵循桌面程序的数据管理方式。
