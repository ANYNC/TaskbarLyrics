## 2026-07-29｜合并外观与窗口为显示与外观并让缩放管控窗口宽度（第一期）

### 变更目的

解决放大缩放后频谱与歌词受限于固定窗口宽度、需切到窗口页手动加宽的协调问题；将原本分离的“外观”与“窗口”设置归一为同一面板，让缩放与宽度同页调节。

### 用户影响

- 原“外观”“窗口”两页合并为“显示与外观”页，侧栏导航 9 项降为 8 项；页内分“布局与封面”“文字样式”“窗口外观”“窗口位置”四个子面板。
- “界面主题”迁至“常规”页（它作用于应用工具界面而非歌词窗口）。
- 歌词区域缩放现在同时管控窗口宽度：实际宽度 = 基础窗口宽度 × 缩放，并限制在屏幕工作区内；缩放预览新增“宽度”读数。
- “窗口宽度”从顶层控件下沉到“高级尺寸微调 → 基础窗口宽度”，改用滑块+数值组件，与其他基础尺寸一致。
- “恢复”改为“恢复 100%”，“恢复推荐比例”改为“重置基础尺寸”（后者现在一并重置基础窗口宽度）。
- 文字样式面板说明补充字号位置提示。
- 第一期宽度仍为像素值；屏幕宽度百分比与一次性迁移留待第二期。

### 技术说明

- 新增 `AppSettings.ClampEffectiveWindowWidth(baseWindowWidth, scalePercent, maxWidth)` 与 `MinimumWindowWidth`/`MaximumWindowWidth`/`DefaultWindowWidth` 常量，集中宽度边界。
- `MainWindow.ApplySettings` 的宽度应用条件由 `WindowLayoutChanged` 扩展为 `WindowLayoutChanged || LyricsLayoutChanged`，使缩放变化也重算宽度；宽度按 `SystemParameters.WorkArea.Width` clamp，与现有主屏定位一致。
- `SettingsWindow` 将 `windowWidth` 纳入 `IsLyricsLayoutSetting` 与 `IsPreviewableSetting`，使基础宽度滑块支持实时预览并刷新有效宽度读数；`CreateLyricsLayoutPreview` 下发 `effectiveWindowWidth`。
- 设置页 `windowWidth` 控件由 stepper 改为 slider+number，复用通用滑块同步；`syncWindowBounds` 增加 windowWidth clamp 以校正越界输入。
- 设置契约测试 `$pages` 同步为 `displayArea`，并新增 `windowWidth` 滑块/数值对校验；web 测试的滑块计数由 6 改为 7。

### 兼容性

- `settings.json` 字段与默认值不变，无数据迁移；`WindowWidth` 仍为 [320,1400] px。默认缩放 100% 时实际宽度与旧版一致。
- WebView V1 信封、消息名、`window.settingsApp`、注入标记均未改变。
- 行为契约变更：缩放行的“窗口宽度…保持不变”承诺被显式替换为“窗口宽度随缩放等比变化”。
- 多显示器定位仍沿用主屏工作区（既有范围未变）。

### 验证

- `scripts/verify.ps1`：Web 14、App 59、Core 26 全部通过；设置契约测试 PASS；`dotnet format --verify-no-changes` 通过；`dotnet build TaskbarLyrics.sln` 零警告零错误。
- 新增 `AppSettingsTests` 覆盖 `ClampEffectiveWindowWidth` 的等比、最小、最大、基础值与缩放越界共 6 个用例。
- 仍需人工确认：缩放滑块拖动时歌词窗口宽度实时跟随；高缩放下窗口不超出屏幕；基础窗口宽度滑块与数值同步；DPI 125%/150% 下显示正常。

## 2026-07-29｜合并尺寸设置并支持隐藏封面

### 变更目的

让整体缩放与基础尺寸微调形成清晰的主从关系，并为不需要封面的歌词展示提供直接、可恢复的显隐控制。

### 用户影响

- 外观页将封面显隐、整体缩放和高级尺寸微调整合为同一“布局与封面”面板；封面开关置于首项，高级参数继续默认折叠。
- 新增“显示封面”开关且默认开启；关闭后歌词占满可用宽度，封面大小、间距和圆角数值保留，重新开启即可恢复。
- 隐藏封面时，歌词窗口高度不再由封面尺寸撑高；高级微调中的封面相关控件会禁用并保留原值，避免产生无效调整。
- 修复隐藏封面后间隔占位被网格自动排到独立行、导致歌词贴近底部并被裁切的问题。
- 关闭封面时，缩放预览明确显示“封面 已隐藏”并隐藏无效的间距读数，避免将保留的基础值误解为当前可见效果。
- 修复高倍率下频谱固定间距占满可用宽度、导致柱宽被压缩至不可见的问题；空间不足时按柱数自适应收缩柱宽和间距，并保留一物理像素下限。

### 技术说明

- `AppSettings.ShowCover` 贯通设置持久化、变更集、设置 WebView V1 载荷和歌词样式载荷；歌词 Web UI 通过根节点状态类切换网格列与封面显示。
- `LyricsLayoutMetrics` 在封面隐藏时仅使用文本高度和最低高度计算窗口高度，同时保留封面有效尺寸，避免修改或丢失用户基础值。
- 设置页继续使用原生 HTML、CSS 和 JavaScript，复用现有面板、开关、依赖禁用和焦点样式，没有引入新的组件样式或前端运行时。

### 兼容性

- 旧 `settings.json` 缺少 `ShowCover` 时由属性默认值保持显示封面；保存后的显隐状态可正常往返读取。
- WebView V1 信封、`window.settingsApp`、歌词注入标记与脚本顺序保持不变，仅扩展既有设置和样式载荷字段。

### 验证

- `scripts/verify.ps1` 通过：Web 测试 14 项、App 测试 53 项、Core 测试 26 项、设置契约和代码格式验证全部通过。
- `dotnet build TaskbarLyrics.sln --no-restore`：0 个警告、0 个错误。
- 回归测试覆盖默认开启、关闭状态持久化、运行时变更识别、隐藏封面后的窗口高度及封面基础值保留。
- 仍需在 Windows 不同 DPI 下手工确认开关即时切换、歌词宽度回收和折叠面板布局。

## 2026-07-29｜统一设置页滑块与保存反馈

### 变更目的

降低滑块配套数字框的视觉侵略感，统一设置页参数调整方式，并让即时预览、键盘操作、输入错误与持久化结果拥有可信反馈。

### 用户影响

- 整体缩放、基础封面间距、基础封面圆角、背景不透明度、X/Y 偏移和取色器色相统一使用“滑块＋紧凑数值输入”；滑块用于快速调整，数字框用于精确输入。
- 数字框默认使用弱背景和淡边框，Hover、Focus、Disabled 状态仍清晰；背景不透明度改为更直观的百分比，色相支持 `0～360°` 精确输入。
- 设置数字在有效时立即预览，确认或失焦后持久化；界面主题支持方向键、Home 和 End 切换。
- 保存状态由宿主真实结果驱动；保存失败时持续提示设置可能在重启后恢复，不再由固定计时器假定成功。颜色格式错误提供持续说明和可访问错误状态。

### 技术说明

- 标准参数滑块复用单一 `.slider-number-control`、`.compact-number-input` 和单位修饰样式；取色器色相仅复用视觉骨架，不进入设置消息协议。
- 数字输入与滑块共用设置键和规范值转换；百分比展示通过组件边界换算，预览继续按动画帧合并，持久化仍使用 V1 `update` 消息。
- `SettingsStore.Save` 返回真实写入结果，宿主通过 V1 `settingsSaveResult` 回传前端；运行时应用与磁盘持久化结果被明确区分。

### 兼容性

- `settings.json` 字段、默认值和原子替换写入方式不变；保存失败仍保留日志与临时文件清理。
- WebView V1 信封结构、`window.settingsApp`、歌词注入标记和脚本顺序保持不变；仅增加宿主到设置页的保存结果消息。
- 生产界面继续使用原生 HTML、CSS 和 JavaScript，没有新增运行时或构建框架。

### 验证

- `scripts/verify.ps1` 通过：Web 测试 12 项、App 测试 51 项、Core 测试 26 项、设置契约和代码格式验证全部通过。
- 回归覆盖全部设置滑块的数值配对、百分比规范值换算、数字即时预览、主题键盘切换、保存失败反馈、颜色错误状态和存储失败返回值。
- 仍需在 Windows 深浅主题、100%、125%、150%、200% DPI、高对比度和 720px 附近窗口宽度下手工检查控件密度、数字与单位文字间距。

## 2026-07-29｜优化缩放与偏移实时调整链路

### 变更目的

在保留歌词区域实时预览的同时，避免拖动滑块时高频持久化，并确保偏移、无障碍反馈和不同 DPI 下的像素对齐结果一致。

### 用户影响

- 整体缩放、封面间距、圆角、背景透明度及 X/Y 偏移继续实时预览；拖动过程更平滑，设置在操作完成时持久化。
- X/Y 数值输入与滑块统一使用 `-2000～2000 px` 的规范值，越界输入会同步收敛，界面与实际窗口位置不再出现差异。
- 缩放拖动过程中不再反复触发屏幕阅读器播报，仅在提交后播报最终比例与有效尺寸。

### 技术说明

- 新增 V1 信封内的 `previewUpdate` 消息类型；前端按动画帧合并预览消息，宿主仅应用临时设置，`change` 提交或设置窗口关闭时才写入磁盘。
- 抽取统一单位输入样式并补齐滑块 Pressed 状态，避免像素与百分比输入重复维护。
- 需要像素对齐的布局几何按当前窗口 DPI 对齐到物理像素；窗口 DPI 变化时重新计算宿主布局、锚点和 WebView 样式，连续字号仍保留小数。

### 兼容性

- `settings.json` 字段与 WebView V1 信封结构保持不变；`window.settingsApp`、歌词注入标记及脚本顺序未改变。
- 旧配置中的小数字号继续原样参与渲染；仅需要锐利边缘的布局几何按物理像素对齐。

### 验证

- `scripts/verify.ps1` 通过：Web 测试 8 项、App 测试 50 项、Core 测试 26 项、设置契约与代码格式验证全部通过。
- 零警告解决方案构建与 `git diff --check` 通过。
- 自动化回归覆盖预览消息合并、最终持久化、XY 越界归一、单次无障碍播报、V1 消息解析以及 125% DPI 物理像素对齐。
- 仍需在 Windows 的 100%、125%、150%、200% DPI、高对比度和窄设置窗口下手工检查拖动观感与布局。

## 2026-07-28｜新增歌词区域整体缩放

### 变更目的

为不局限于任务栏区域的歌词展示提供统一尺寸调整能力，在放大或缩小时保持字号、封面、间距和内部布局的视觉比例。

### 用户影响

- 外观页新增 `25%～300%` 的歌词区域整体缩放，可通过滑块和数字输入即时预览，并显示实际字号、封面和间距。
- 字体样式与尺寸设置重新分组；基础字号、封面尺寸、间距和圆角收纳到默认折叠的高级尺寸微调，并支持分别恢复 `100%` 倍率和推荐比例。
- 字号与封面的安全范围开关从界面移除，基础值直接使用扩展硬边界。

### 技术说明

- 新增统一歌词布局计算边界，从基础值与独立倍率一次性生成有效尺寸；字号等连续渲染值保留小数，需要像素对齐的布局几何取最近整数，窗口高度向上取整。
- WPF 宿主、原生窗口高度、设置页实际值预览和歌词 WebView 共用同一计算结果；未使用 CSS `scale()`，窗口宽度和 X/Y 偏移不参与缩放。
- 缩放引起窗口高度变化时保持任务栏锚点中心稳定，仅在接近主屏幕边缘时收敛到可见区域；频谱和歌词内部间距同步消费缩放后的几何尺寸。

### 兼容性

- 旧 `settings.json` 缺少倍率字段时默认使用 `100%`，原有基础字号和封面小数值不迁移、不反写；旧安全范围字段继续无损读写，但不再参与运行时限制。
- WebView V1 信封保持不变，新增布局预览与恢复推荐比例消息；歌词缓存、单曲偏移数据库、用户数据和发布结构无变化。

## 2026-07-26｜修复旧版歌词缓存导致检索失败

### 变更目的

解决旧版本建立的歌词缓存被新版本读取后，可能阻止正常在线检索或造成已有歌曲无法命中的问题。

### 用户影响

- 升级后会自动淘汰不再安全的旧版缓存，无需依赖手动清除缓存恢复检索。
- 无效缓存不会阻断后续歌词搜索。

### 技术说明

- 将统一歌词缓存格式升级为 V10，并在初始化时清理 V8/V9 缓存文件。
- 持久化缓存只使用播放器提供的稳定歌曲 ID；缺少稳定 ID 的模糊元数据匹配不再写入持久缓存，避免错误结果长期粘滞。
- 缓存缺失或无效时继续执行远程检索，并增加对应回归测试。

### 兼容性

- 不迁移或复用不再安全的 V8/V9 缓存内容，而是自动失效后按需重新检索。
- 当前缓存目录、设置格式和歌词来源顺序不变；有效的新结果写入 V10 缓存。

### 验证

- `LyricProviderBaseTests` 覆盖旧缓存回退场景。
- 关联提交：`fb031c3`。
