## 记录规则

- 以一个可独立验证的功能、修复或重构阶段为一条记录，不按对话轮次、文件修改次数或临时尝试记录。
- 记录用户影响、关键技术说明、兼容性、验证证据和仍需跟进的事项。
- 新功能、缺陷修复、数据迁移、协议调整、架构变更和重要工程规范需要记录；纯格式化、机械重命名和无行为影响的小调整不单独记录。
- 完整变更验收时更新本文。面向普通用户的内容仍应在发布时汇总到 README 或版本更新日志。
- 新记录固定插入本节之后，按日期倒序排列；同一天的记录按完成时间倒序排列，最新完成的在最前。禁止把新记录追加到旧记录之后，“新记录模板”永久保留在文件末尾。关联提交、Issue 或 PR 只在有助于追溯时填写。
- 本文从 2026-07-26 的近期重大变更开始建立历史基线，不追溯复述此前的每个提交。

## 2026-07-28｜修复重启后歌词缓存阻断检索

### 变更目的

修复统一歌词缓存写入成功但应用重启后无法反序列化，进而导致网易、QQ、酷狗歌词源在远程检索前同时失败的问题。

### 用户影响

- 已缓存歌词可在应用重启后正常恢复，不再需要清除缓存并重新切歌。
- 损坏或与当前模型不兼容的歌词缓存会自动失效，应用继续执行远程检索。

### 技术说明

- 为 `LyricDocument` 增加与只读歌词行属性精确匹配的 JSON 构造契约，同时保留现有可枚举集合构造入口。
- 缓存存取边界将 JSON 模型契约异常视为可恢复故障；不可读缓存删除失败时保留明确日志，不影响歌词检索结果。
- 增加 `LyricDocument` 跨缓存实例磁盘往返和不兼容缓存安全失效回归测试。

### 兼容性

- V10 缓存文件名、缓存键和 JSON 字段保持不变，现有有效 `unified-lyrics-v10.json` 可直接读取。
- `settings.json`、WebView V1 协议、用户数据库与发布结构无变化。

### 验证

- 定向缓存与歌词提供方测试 10 项通过；完整 Core 测试 26 项、App 测试 41 项、Web 测试 5 项及设置契约测试通过。
- 隔离输出目录解决方案构建：0 个警告、0 个错误；本次涉及文件的格式验证与 `git diff --check` 通过。
- 使用修复后的程序集从现有 V10 缓存副本成功恢复磁盘缓存歌词，原缓存未被清除或改写；应用已重启供手工复核。
- 全量 `scripts/verify.ps1` 的测试阶段通过；全量格式阶段仍被仓库既有文件的换行与编码问题阻挡。

## 2026-07-26｜修复旧版歌词缓存导致检索失败

### 变更目的

解决旧版本建立的歌词缓存被新版本读取后，可能阻止正常在线检索或造成已有歌曲无法命中的问题。

### 用户影响

- 升级后会自动淘汰不再安全的旧版缓存，无需依赖手动清除缓存恢复检索。
- 无效缓存不会阻断后续歌词搜索。

### 技术说明

- 将统一歌词缓存格式升级为 V10，并在初始化时清理 V8/V9 缓存文件。
- 持久化缓存只使用播放器提供的稳定歌曲 ID；缺少稳定 ID 的模糊元数据匹配不再写入持久缓存，避免错误结果长期粘滞。
- 缓存缺失或无效时继续执行远程检索，并增加对应回归测试。

### 兼容性

- 不迁移或复用不再安全的 V8/V9 缓存内容，而是自动失效后按需重新检索。
- 当前缓存目录、设置格式和歌词来源顺序不变；有效的新结果写入 V10 缓存。

### 验证

- `LyricProviderBaseTests` 覆盖旧缓存回退场景。
- 关联提交：`fb031c3`。
